
# Employee Management Dashboard
## Day 1 - Component Tree

```text
Employee Dashboard
│
└── App
    │
    ├── Header
    │
    ├── Sidebar
    │
    ├── Dashboard
    │   ├── SummaryCard (Total Employees)
    │   ├── SummaryCard (Active Tasks)
    │   ├── SummaryCard (Completed Tasks)
    │   └── Recent Employees
    │
    ├── Employees
    │   ├── Employee Form
    │   └── Employee List
    │
    ├── Tasks
    │   ├── Add Task Form
    │   └── Task List
    │
    └── Settings
```

## Concepts Used

1. JSX - HTML-like syntax inside JavaScript.
2. Functional Components - Reusable UI components.
3. Props - Passing data between components.
4. State - Managing data using useState.
5. Events - Handling clicks and form submissions.
6. Component Composition - Combining components to build the dashboard.
