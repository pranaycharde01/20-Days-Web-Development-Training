# Day 1 – Employee Management Dashboard

## Project Overview

The Employee Management Dashboard is a responsive web application developed using React. It helps manage employee information and tasks through a simple and user-friendly interface.

This project was developed as part of the 20-Day Web Development Internship Training.

## Features

- Dashboard with summary cards.
- View employee information.
- Add new employees.
- Edit existing employee details.
- Delete employees.
- Search employees.
- Add and manage tasks.
- Update task status.
- Delete tasks.
- Settings section.
- Reusable React components.
- Component-based application structure.
- State management using React Hooks.
- Event handling and props.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## Concepts Practiced

### 1. React Components
Created reusable components to organize the application.

### 2. Props
Passed data between parent and child components.

### 3. State Management
Used React state to manage employees, tasks, and application data.

### 4. Event Handling
Implemented button clicks, form submissions, search, and other user interactions.

### 5. Component Reusability
Organized the application into smaller and reusable components.

### 6. Responsive Design
Created a user interface that adapts to different screen sizes.

## Installation and Setup

1. Clone or download the project.
2. Open the project folder in VS Code.
3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in the terminal.

## Learning Outcome

Learned the fundamentals of React development, including components, props, state management, event handling, and building reusable user interface elements.
